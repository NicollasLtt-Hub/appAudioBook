# 🎧 Hashtag Audiobook

Este é um projeto desenvolvido durante o **Intensivão de JavaScript**, focado na criação de um reprodutor de audiobook interativo. O objetivo principal foi aplicar conceitos fundamentais de desenvolvimento web para manipular elementos de mídia e interface em tempo real.

## Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do player.
* **CSS3:** Estilização moderna e layout responsivo.
* **JavaScript:** Lógica de controle de áudio, eventos e manipulação do DOM.

## Funcionalidades

* **Reproduzir/Pausar:** Controle total sobre o fluxo do áudio.
* **Troca de Faixas:** Navegação entre diferentes capítulos do livro.
* **Indicador de Progresso:** Atualização visual baseada no tempo do áudio.
* **Troca Automática:** Avanço automático para o próximo capítulo ao finalizar o atual.

2. Navegue até a pasta do projeto.
